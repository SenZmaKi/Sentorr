These files are unchanged reference snapshots of VoltAgent's analyses, not official brand specifications or agent instructions. They contain marketing-only patterns, conflicting rules and known gaps. Sentorr's authoritative merged rules are in [DESIGN.md](../../DESIGN.md).

## Merge decisions

- Resend supplies neutral bright actions and restrained dark styling. The user-supplied depth frames supersede its surface values and shadow restrictions.
- Vercel supplies Geist type hierarchy and 4-unit rhythm. The depth frames guide light-mode surface separation and elevation.
- Use Geist Sans and Geist Mono for the whole app. Resend's commercial serif and marketing font stack are unnecessary for the agreed simple app direction.
- Complete both modes with semantic status pairs, interaction states, control boundaries, text scaling and explicit playback-overlay roles. These are Sentorr adaptations rather than claims from the reference analyses.
- Prefer app-sized components over marketing hero sizes/pill CTAs. Media artwork replaces developer marketing illustrations; ambient glows and mesh gradients are outside the initial app treatment.
- Keep one identity and light/dark/system selection. Additional identities will implement the same semantic and component contracts.

No Flutter theme code or product UI is implemented by this documentation change.

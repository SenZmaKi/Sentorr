# Spool

[Spool's approved concept sheet](spool-baseline.png) is the baseline for future Sentorr mascot artwork. Supply it as the visual reference when generating new poses, expressions, or scenes. The sheet shows the light and dark treatments and simplified marks for small sizes.

Spool is a ghost fused with a cinema projector. His signature features are a single five-hole reel, a short film feed, a lens for one eye, a sleepy smirk, and a curling film-strip tail.

Match Sentorr's layered monochrome style with matte gray surfaces, fine edge highlights, and soft shadows where parts meet. Use shallow depth around the recessed reel holes, the layered lens, and the tail fold. Keep the shapes broad and the hardware detail restrained.
